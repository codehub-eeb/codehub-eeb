### 2. Intellecta – AI-Powered Study Assistant

Intellecta is an AI-powered study assistant designed to make learning easier and smarter for students. It helps students understand concepts, prepare exam-oriented answers, and analyze study materials using Google's Gemini AI.

**Technologies:** Python, Streamlit, Google Gemini API

**Key Features:**
- Normal Mode for general AI conversations and assistance
- Study Mode for exam-oriented answers
- Generates answers in 2, 5, 7, and 10-mark formats
- PDF and image uploads for AI-powered content analysis
- Multi-file upload and analysis
- Gemini multimodal AI integration
- Quick prompts for faster interactions
- Chat History to access previous conversations
- Interactive and user-friendly interface

🔗 [Live Demo](https://intellecta-ai-study-assistant.streamlit.app/Z) | [Source Code](https://github.com/codehub-eeb/INTELLECTA)
